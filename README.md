# MILITECH

Подготовлено для GitHub Pages. Инструкция публикации — [GITHUB-PAGES.md](GITHUB-PAGES.md). До включения Pages и успешного deployment публичная ссылка не подтверждена.

Законченный демонстрационный сайт строительной компании для портфолио ELEMENT DIGITAL. Все тексты на русском, адаптивная верстка, четыре проекта, фильтры, услуги, принципы работы, этапы, FAQ и локальный калькулятор с валидацией и скачиванием результата.

## Стек

Next.js 16 (App Router), React 19, TypeScript, Tailwind CSS 4, Lucide. Manrope загружается локально. Изображения оптимизированы в WebP и включены в проект. Внешние API и аккаунты для запуска не нужны.

## Требования и запуск

Node.js 22.9+ (проверено на Node.js 24), npm.

```bash
npm ci
npm run dev
```

Откройте http://localhost:3000.

## Production

```bash
npm run typecheck
npm run build
npm start
```

Для другого порта: `npm start -- --port 3001`.

Деплой на Vercel: импортировать папку проекта, выбрать Next.js, команда сборки `npm run build`. Для собственного Node-сервера: выполнить `npm ci`, `npm run build`, затем `npm start` под процесс-менеджером.

Для самостоятельной production-сборки задайте `NEXT_PUBLIC_SITE_URL` с origin сайта (без пути репозитория). Для GitHub Pages workflow задаёт origin и `NEXT_PUBLIC_BASE_PATH` автоматически. При локальном запуске оставьте `NEXT_PUBLIC_BASE_PATH` пустым. Резервный origin в metadata — `https://kerbalis1.github.io`; путь сайта задаёт `NEXT_PUBLIC_BASE_PATH`.

## Статический хостинг

```bash
npm run build:static
```

Результат — папка `out/`. Разместите её содержимое на статическом хостинге. Все взаимодействия работают в браузере. Для последующего `npm start` снова выполните обычную `npm run build`.

## Поведение калькулятора

- Газобетон: 80 000 ₽/м²; каркасный: 65 000 ₽/м²; кирпич: 90 000 ₽/м².
- Площадь от 50 до 500 м², имя от 2 до 60 букв, российский номер телефона из 11 цифр, начинающийся с 7 или 8.
- Ошибки отображаются рядом с полями, связаны через `aria-describedby`; фокус переходит на первое ошибочное поле.
- Успешный результат показывает бюджет и позволяет скачать текстовый расчёт без персональных данных.
- Контакты не отправляются, не записываются в localStorage и не сохраняются на сервере. Состояние сбрасывается при перезагрузке.
- Выбор дома в портфолио подставляет площадь и технологию. Ручное изменение параметров снимает отметку выбранного проекта.

Демонстрационная форма реализована полностью на front-end. Для приёма настоящих заявок требуется отдельно подключить серверный обработчик или CRM и добавить действующие условия обработки персональных данных.

## Доступность и оптимизация

Семантические landmarks, один h1, skip-link, видимый keyboard focus, доступные подписи кнопок и полей, раскрытие FAQ нативными details/summary, Escape для мобильного меню. Учтён `prefers-reduced-motion`; контент доступен и без анимаций. Главное изображение загружается приоритетно с мобильным вариантом; изображения проектов — лениво. Нет фоновых видео, каруселей и тяжёлых анимационных библиотек.

## SEO и демонстрационный статус

В layout заданы title, description, Open Graph, Twitter Card, lang, viewport и favicon. Индексация сознательно отключена (`noindex, nofollow` и robots.txt): сайт остаётся демонстрационным проектом портфолио. Для реального сайта нужно заменить демонстрационные сведения и настройки robots.

В футере присутствует точный текст «Демонстрационный проект ELEMENT DIGITAL». Контактный блок не использует чужие телефоны или адреса. Портфолио и цены явно обозначены как примеры. Отзывов и вымышленных реальных клиентов нет. Архитектурные изображения созданы с помощью ИИ специально для этого проекта.

## Файлы

- `app/layout.tsx` — шрифты, metadata, Open Graph, язык страницы.
- `app/page.tsx` — главная страница.
- `app/globals.css` — Tailwind, дизайн, все адаптивные состояния и анимации.
- `app/not-found.tsx` — русскоязычная страница 404.
- `components/Home.tsx` — контент, фильтры, меню, FAQ, калькулятор и скачивание.
- `public/icon.svg` — фирменная иконка.
- `public/robots.txt` — запрет индексации демонстрационного сайта.
- `public/images/hero.webp`, `hero-mobile.webp` — главное архитектурное изображение.
- `public/images/project-0.webp` … `project-3.webp` — четыре проекта.
- `public/images/og.jpg` — изображение для социальных сетей.
- `package.json`, `package-lock.json` — команды и зафиксированные зависимости.
- `lib/assets.ts` — единые пути к изображениям и favicon с учётом GitHub Pages.
- `.github/workflows/pages.yml` — сборка и публикация через GitHub Actions.
- `GITHUB-PAGES.md` — включение Pages и настройки публикации.
- `next.config.ts`, `tsconfig.json`, `postcss.config.mjs`, `next-env.d.ts` — конфигурация.
- `scripts/build-static.mjs` — кроссплатформенная команда статического экспорта.
- `.env.example`, `.gitignore`, `AGENTS.md` — настройки и инструкции.
- `QA.md` — результаты проверки сборки, поведения, мобильной версии и UX.

`node_modules/`, `.next/` и `work/` не входят в исходный архив. Для воспроизводимой установки используйте `npm ci`.
