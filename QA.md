# Проверка MILITECH

Проверено 7 октября 2026 года в Chromium, Node.js 24.19.0, Next.js 16.4.0.

## Сборка и запуск

- `npm ci` — установка по package-lock; исходная установка зависимостей выполнена успешно.
- `npm run typecheck` — пройдено.
- `npm run build` — пройдено, главная и 404 предварительно отрендерены.
- `npm run dev` — сервер запущен, главная возвращает HTTP 200.
- `npm start -- --port 3002` — production-сервер запущен, browser QA выполнен на production-сборке.

## Автоматические браузерные сценарии

Проверены:

1. Четыре карточки домов и фильтрация до одного скандинавского проекта.
2. Подстановка площади 120 м² и каркасной технологии при выборе дома.
3. Ошибки площади 49 м², пустого имени и неверного телефона; фокус первого ошибочного поля.
4. Неверный телефон отдельно после исправления площади и имени.
5. Корректный расчёт: каркасный дом 180 м² — от 11 700 000 ₽.
6. Success-состояние, скачивание TXT и возврат к редактированию.
7. Раскрытие FAQ.
8. Меню на мобильном экране; закрытие Escape, возврат фокуса кнопке меню, закрытие при переходе к форме.
9. Отсутствие ошибок JavaScript во всех сценариях.
10. Отсутствие горизонтального переполнения на 320, 375, 390, 640, 768, 1024 и 1440 px.

## Доступность

axe-core: правила WCAG 2 A/AA и WCAG 2.1 AA, размеры 1440 и 390 px, в том числе раскрытые ответы FAQ. **0 автоматических нарушений** на обоих размерах. Это результат автоматической проверки, а не полная сертификация доступности.

Найденный недостаточный контраст второстепенных текстов исправлен. Добавлены более тёмные оттенки подписей и более заметные границы полей. Сохранены skip-link, labels, aria-invalid, aria-describedby, сообщения role=alert/status и поддержка reduced-motion.

## Визуальный UX-аудит

Первый экран, весь desktop-макет, мобильный макет и форма просмотрены на скриншотах.

- Заголовок и главный CTA читаются поверх изображения.
- Вторичная кнопка ведёт к портфолио, выбор карточки — к уже заполненным параметрам.
- Sticky header сохраняет доступ к навигации. Якоря учитывают его высоту.
- На телефоне кнопки расположены вертикально, проекты — в одну колонку, поля — в одну колонку.
- Мобильные поля используют шрифт 16 px для предотвращения автоматического увеличения страницы на iOS.
- Параметры и цена стоят рядом; демонстрационный статус виден до заполнения формы.
- После ручного изменения площади или технологии отметка выбранного проекта снимается.
- Результат можно сохранить; телефон и имя не попадают в скачанный файл.
- Реальных отзывов и неподтверждённых показателей опыта нет.
- Контакты и реальные заявки не имитируются: ограничения демо указаны прямо на сайте.

## Ограничения проверки

Браузерные проверки выполнены в Chromium. Отдельные реальные устройства Safari/iOS и Firefox не использовались. Backend/CRM отсутствует по scope: реализована front-end демонстрация. Демонстрационная версия подготовлена к публикации через Sites с приватным доступом владельца.

## Статический экспорт

`npm run build:static` — пройдено. Созданы `out/index.html`, `out/404.html`, локальные изображения, шрифты, JavaScript и CSS. Команда экспорта использует Node-скрипт и работает без POSIX-синтаксиса переменных окружения.

Статическая сборка дополнительно запущена на обычном HTTP-сервере: проверены фильтры и успешный расчёт на мобильном экране. Ошибок загрузки ресурсов и JavaScript нет. Скриншоты сохранены в `work/`.
